说明

  • 生成时优先挑还没被用过的词，每生成一次就自动往下轮，形成复习节奏。
  • 文中目标词会高亮，可一键「遮挡自测」；导出支持 Markdown / Word / HTML / 纯文本。
  • 添加到主屏幕后可以离线打开，但生成文章需要联网（要调模型）。
  • iOS 上清理 Safari 数据会连本地词库一起清掉，定期导出备份。
